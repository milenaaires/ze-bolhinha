# Materiais internos

Use esta pasta para fontes do Notion que não devem aparecer automaticamente no GitHub Pages, como registros de entrevistas, listas de participantes, feedbacks individuais, transcrições, atas internas e documentos ainda em revisão.

A pasta não é publicada pelo site. Antes de mover qualquer arquivo para `docs/`, revise o conteúdo e confirme que todas as pessoas citadas autorizaram a divulgação necessária.
