# Materiais internos

Use esta pasta para notas internas que não devem aparecer no GitHub Pages, como rascunhos e documentos ainda em revisão. Registros de entrevistas, listas de participantes, feedbacks individuais e transcrições não entram aqui: ficam na pasta RESTRITO do Drive do grupo.

A pasta não é publicada pelo site. Antes de mover qualquer arquivo para `docs/`, revise o conteúdo e confirme que todas as pessoas citadas autorizaram a divulgação necessária.

**Visibilidade:** este repositório é público. Arquivos desta pasta podem ser acessados no GitHub, embora não apareçam no site Pages. Não use esta pasta para guardar dados pessoais ou material que precise de acesso restrito.
